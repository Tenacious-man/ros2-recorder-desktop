# ROS Recorder v0.4.0

发布日期：2026-11-04。

本版新增管理员入口和双点云手动标定，同时调整空间单位与界面提示。

## 改动

- 连续点击左上角“ROS Recorder”六次，首次设置管理员密码，后续验证密码后显示管理员功能。支持修改密码、退出管理员模式；重启后入口重新隐藏。
- 新增“点云标定”：每路选择 PointCloud2 话题后自动订阅，约每 5 秒后台刷新话题，也保留手动刷新。切换或清空选择自动更新订阅，离开页面自动停止，返回后自动恢复。
- 页面内提供红白点云叠加、三维旋转 / 平移 / 缩放、XYZ 与 Roll / Pitch / Yaw 调整，以及选点属性查看。数据由外部驱动或播放器提供，暂停后保留最后一帧供微调。
- 支持旧标定工具的 INI 读取、保存和相对外参导出。界面使用米，INI 平移使用厘米。待标定组采用微调增量左乘已加载外参的规则。
- 点云标定只订阅和本地预览，不发布点云或外参话题。管理员设置和标定模块独立于录制数据与配置。
- 目录剩余空间改用十进制 GB。
- 删除底部全局提示栏，保留右上角当前 ROS 环境信息；退出等待状态显示在窗口标题。
- deb 增加 NumPy 依赖，包含新增模块和操作说明。

## 使用和安装

```bash
sudo apt install ./ros2-recorder-desktop_0.4.0-1_all.deb
```

启动 `ros2-recorder`，或在应用菜单选择“ROS 2 录制工作台”。升级后重新打开软件。已有录制配置保持兼容，管理员密码单独保存在用户配置目录，不随安装包分发。

## 当前范围

点云标定为两个标准 `sensor_msgs/msg/PointCloud2` 话题的手动外参调整；每路最多预览 20,000 个点、每秒最多更新 5 次。暂不包含自动标定、帧配对、去畸变或内置播放。“设备授时”仍为预留入口。实际高带宽传感器与其他目标系统仍需实机验证。

ROS 2、设备驱动和私有消息包由目标机器提供；deb 不包含这些组件，也不包含个人配置、录制数据或编译缓存。
