# 点云标定

该页面直接集成在 record 的“点云标定”中，沿用已有 `lidar_calibration_panel` 工具的变换约定与 INI 格式。界面和三维视图属于 record，无需原工具目录或外部 RViz 窗口。首版处理两个标准 `sensor_msgs/msg/PointCloud2` 话题，提供手动调整；没有内置播放器、自动求解、帧同步或运动去畸变。

## 使用

1. 在“消息环境”加载驱动或外部播放所用的 ROS 2 环境，确认 Domain 一致。
2. 连续点击左上角标题六次，通过管理员密码验证，进入“点云标定”。
3. 在外部启动传感器驱动或播放 bag。进入标定页后会立即在后台发现话题，之后约每 5 秒自动刷新；“刷新”按钮可随时手动刷新。每一路选择好 PointCloud2 话题后就会自动订阅，也可输入完整话题名。切换话题会自动更换订阅，清空某一路则取消该路订阅。
4. 白色为基准、红色为待标定。左键拖动旋转，中键或右键拖动平移，滚轮缩放，双击适配点云。
5. 在右侧标签页选择调整对象，使用数值框或滑块修改 Roll、Pitch、Yaw 和 XYZ。角度单位为度，平移单位为米。
6. 可以在外部暂停播放；最后收到的原始点云会保留，微调每次都基于原始点云，不会反复叠加上一次的变换。
7. 单击显示的点，展开点属性，查看原始 / 变换后 XYZ、原始点索引，以及消息实际包含的 intensity、ring、time 等字段。
8. “保存 INI”保存当前组到共同坐标系的外参。“导出待标定 → 基准 INI”保存两组外参计算得到的相对变换。

本页没有开始 / 停止订阅按钮或冻结预览控件，不管理外部播放的进度与速度。后台刷新保留当前选择，未选择的话题不会自动选中。点云显示会抽样，每路最多 20,000 个点、每秒最多更新 5 次；选点属性属于实际显示的原始采样点。界面显示每路原始点数、预览点数、frame_id 和 header.stamp，时间差仅为最后收到两帧的差值，没有做帧配对。

## 外参和旧文件

列向量约定：`p_target = T × p_source`，旋转顺序为 `Rz(yaw) × Ry(pitch) × Rx(roll)`。

- 每组外参表示该点云原始坐标到共同目标坐标系的变换。
- 待标定组读取文件后，文件矩阵作为基准，控件从零开始，最终矩阵为 `T_adjustment × T_loaded`。
- 基准组读取文件后，分解为控件中的姿态和平移，沿用旧工具的绝对调整方式。
- 相对外参为 `inverse(T_reference) × T_input`，表示待标定点云原始坐标到基准点云原始坐标。
- INI 支持 `Rotate` / `Translate` 以及完整 `transformation`。文件平移单位为厘米，读取时除以 100，保存时乘以 100。
- 保存采用临时文件写完再替换；格式错误、缺行、非有限数值或不合法的刚体矩阵会拒绝读取，不覆盖当前调整。
- “清零调整”保留待标定组已加载的基准矩阵；“单位矩阵”同时清除该组的基准矩阵与调整。

## 数据与进程

ROS 订阅位于独立子进程中，沿用当前消息环境，采用 best-effort、深度 1，处理最近消息，不累积历史帧。GUI 不加载 ROS 消息库。标定订阅期间暂停原频率检测，并阻止启动录制、切换配置或消息环境。离开标定页、清空两路选择、退出管理员模式或关闭软件时会自动停止订阅，恢复频率检测；重新进入标定页会按保留的选择自动订阅。同一消息环境中保留最后预览帧，切换环境后会清除旧环境的缓存画面。

点云和调整结果仅在页面内显示，外参通过 INI 文件保存或导出，不发布点云或外参话题。后台只接收原始点云，保留采集时间戳、原始 frame_id 和选点属性；六轴微调在界面中计算，不修改原始输入消息。

使用静态场景、合适的同步帧或外部暂停帧判断重合效果；仅凭两团点云看起来重合不能证明标定精度。原始毫米波目标列表等其他消息类型，需要驱动提供 PointCloud2 后才能使用本页。
